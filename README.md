## Selected work

- **[FinAgent](https://github.com/Thanhizme/FinAgent)** · Python, pandas, NumPy, scikit-learn, Streamlit<br>
  An eight-stage quant research pipeline. It ingests market, news and macro data (yfinance, NewsAPI, FRED), builds indicators and trading signals, and runs a vectorised backtest with transaction costs and slippage. On top of that sit portfolio optimisation (Max Sharpe, Risk Parity) and a risk overlay with 95%/99% historical VaR.

- **Gold market volatility research** · Python, SciPy, statsmodels, PyTorch<br>
  First-author manuscript in preparation on macroeconomic volatility and overnight price transmission in Vietnam's gold market, 2015–2026. A GARCH-MIDAS model separates short-run volatility from macro-driven long-run volatility. Under strict walk-forward evaluation, none of the ML models tested (elastic net, gradient boosting, LSTM) beat it.

- **[LMS](https://github.com/Thanhizme/lms-db)** · React, TypeScript, Flask, Azure SQL, Docker<br>
  A multi-role learning platform for students, tutors and admins, built by a team of five. I worked across the React/TypeScript front end and the Flask REST API over Azure SQL stored procedures. It shipped through Docker and GitHub Actions to Azure App Service.

- **[EventEase](https://github.com/Thanhizme/EventEase)** · React, Node.js/Express, SQL Server, scikit-learn, Gemini API<br>
  An event ticketing platform with a Random Forest sell-out predictor served inside the product. It also generates marketing copy with Gemini and validates the output against a JSON schema.

- **[Lumbar MRI Database](https://github.com/Thanhizme/Database-Management-Systems-CO3021-)** · SQL Server, MongoDB, Python<br>
  A team database project at HCMUT. We built a 3NF schema and a Python ETL pipeline for 48k MRI image records, then benchmarked indexing and concurrency control in SQL Server and MongoDB.
